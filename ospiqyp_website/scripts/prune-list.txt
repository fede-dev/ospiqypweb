# Rutas a borrar del hosting con:
#     python3 scripts/deploy_cpanel.py --creds ~/.ospiqyp_deploy prune
#
# Formato: una ruta por línea, RELATIVA a CP_DIR (public_html).
#   - Las líneas vacías y las que empiezan con # se ignoran.
#   - Sin barra final = archivo, se borra con DELETE.
#   - Con barra final = directorio, se borra con RMD y sólo si quedó vacío
#     (por eso los archivos de adentro van listados ANTES que el directorio).
#   - Nada de rutas absolutas, '..' ni comodines: el script las rechaza.
#
# El deploy sube out/ pero nunca borra: lo que se sacó del repo sigue vivo en el
# server hasta que se lo liste acá. Las rutas ya borradas se dejan escritas como
# registro de qué se sacó; prune las reporta como "ausente" y sigue de largo.
